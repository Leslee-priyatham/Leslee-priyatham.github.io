Gemini Invoice Agent

Document processing with visible checks

What I built

A local agent that extracts invoice fields with Gemini, routes tasks, verifies totals with Decimal arithmetic, and retrieves cited policy evidence.

How I checked it

Offline tests cover routing and validation while the interface exposes tool names, evidence, and result summaries.

Current limits

It is single-user, handles one image at a time, and does not approve expenses or use real company policy.
